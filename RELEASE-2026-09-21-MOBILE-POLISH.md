# Sweety Aquatics — Mobile Polish Release

## Included
- Added the EN / தமிழ் language selector inside the mobile navigation drawer.
- Made Care Tips easy to discover in mobile navigation and added a care-hub fallback CTA when no articles are published.
- Optimized the living-aquarium canvas for mobile (lower backing resolution, fewer bubbles, bounded frame rate).
- Pauses canvas animation when the tab is hidden or the hero is outside the viewport.
- Reduced heavy mobile compositing effects and improved safe-area spacing for bottom navigation.

## Deploy
1. Extract this release and copy its contents into your existing local `sweety-aquatics` clone, replacing files when prompted.
2. Open GitHub Desktop and review the changed files.
3. Commit with: `Polish mobile experience and aquarium performance`
4. Push origin. Vercel will redeploy automatically if Git integration is enabled.

The source has not been connected to your live hosting account from here. Verify the Vercel build and test on your phone after deployment.
