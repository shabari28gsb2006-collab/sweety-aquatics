# Sweety Birds & Fishes — SEO, favicon & custom collections release

## Included
- Favicon exports: PNG 16×16, 32×32, 48×48; multi-resolution ICO; Apple touch icon 180×180; Android icons 192×192 and 512×512.
- Brand mark export and web manifest.
- SEO foundation: descriptive title/description, robots directives, Open Graph/Twitter metadata, PetStore JSON-LD, route-aware browser titles/descriptions, robots.txt.
- Seller-managed custom storefront collections with image upload, name, description, visibility, and mapping to an existing product group. Persisted in ContactSettings JSON.
- Responsive polish: safe-area support, mobile tap sizing, 16px form text floor, reduced-motion support.

## Deploy
1. Backend: `cd backend && npm install && npx prisma generate && npx prisma migrate deploy && npm run build`
2. Frontend: `cd frontend && npm install && npm run lint && npm run build`
3. Deploy frontend and backend using the existing deployment guide/environment variables.
4. In seller admin, open **Store & Contact Settings → Create premium categories**, upload a 1600×1000 image, choose the product group, then save & publish.
5. Once the final public domain is confirmed, add its absolute canonical URL and sitemap URLs. This project is a client-rendered SPA; prerendering/SSR is recommended for full per-product search indexing.
